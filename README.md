# 🌦️ Weather Website

A modern and responsive weather website built using HTML, CSS, and JavaScript.  
It provides real-time weather information, forecasts, weather-based backgrounds, air quality, and more.

## 🔗 Live Demo

👉 https://aritraghorai053.github.io/Weather-Website/

## ✨ Features

- 🔍 Search weather by city
- 📍 Current location weather
- 🌡️ Real-time temperature
- 🌤️ Dynamic weather icons
- 🎥 Weather-based video backgrounds
- 💧 Humidity information
- 💨 Wind speed and direction
- 🌧️ Rain probability
- 📅 7-day weather forecast
- 🕐 Hourly weather forecast
- 📈 Temperature chart
- 🌫️ Air quality information
- 🌅 Sunrise and sunset
- 🏃 Outdoor activity suggestions
- 🌙 Dark / Light mode
- 📱 Fully responsive design
- ❌ Invalid city error handling

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API
- Font Awesome
- Git & GitHub
- GitHub Pages
